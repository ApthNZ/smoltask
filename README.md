# smoltask

> ### ⚠️ This was written by an AI. Don't run it in production.
>

> working from a specification. A human reviewed the behaviour and steered the
> design; a human did not audit the code.
>

**A notebook that ticks.** A task takes two seconds to write and one key to be
rid of. That is the whole feature list.

The design this is being built from is in [DESIGN.md](DESIGN.md). The code lands
on top of it in the order set out there; this README grows as it does.
